# Использование ИИ

- OpenCode помог подготовить каркас, расчётное ядро, API, интерфейс, демоданные и тесты.
- UI/UX Pro Max использован для выбора визуальной системы операционной панели; принятые правила описаны в [`ui/DESIGN.md`](ui/DESIGN.md).
- Тарифы и критерии оценки взяты из бизнес-модели команды. Неизвестные комиссии продавца не подставлялись.

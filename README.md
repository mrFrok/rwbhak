# RWB Mesh

Хакатон-проект команды из трёх человек. Пункты выдачи становятся микро-складами: заказ выдаётся с полки (**A**), едет прямым рейсом между ПВЗ (**B**) или уходит через хаб (**C**). Решатель показывает, какие условия повлияли на выбор. Данные синтетические; суммы — допущения команды, не тарифы RWB.

## Быстрый старт

```bash
git clone https://github.com/mrFrok/rwbhak.git
cd rwbhak
cp .env.example .env
make up
```

- Интерфейс: <http://localhost:8090> (если порт занят, поменяйте `UI_PORT` в `.env`)
- Swagger: <http://localhost:8000/docs>

Docker Compose поднимает React (Nginx), FastAPI и PostgreSQL. API при запуске создаёт таблицы через `create_all` и заполняет пустую БД демоданными. Повторный запуск не сбрасывает её. `make reset-demo` **удаляет текущие данные демо** и загружает исходный сценарий. Сервис без авторизации, порты по умолчанию открыты только на `localhost`.

### Разработка без Docker

Нужны Python 3.12+ и Node.js 22+.

```bash
make install
.venv/bin/python -m data.seed   # локальная SQLite
make test
.venv/bin/python -m core.breakeven
```

В двух терминалах запустите `make dev-api` и `make dev-ui`. Откройте <http://localhost:5173>. `make build-ui` проверит TypeScript и соберёт фронтенд.

Для проверки в браузере на свежих демоданных: `.venv/bin/pip install playwright`, затем `.venv/bin/python -m playwright install chromium` и `.venv/bin/python tests/browser_smoke.py`. Сценарий меняет данные демо.

## Сценарии демо

На свежих данных рейс «ПВЗ Мира → ПВЗ Компрос» уже содержит 99 синтетических заказов класса S.

1. **Рейс B.** В разделе **ПВЗ → Заказы** выберите **Создать заказ → Городской рейс**. Сотый заказ показывает **95 ₽ против 109 ₽**. Соберите заказ; в **Рейсах** отправьте нужный рейс и отметьте прибытие. Вернитесь в **Заказы**, выдайте заказ и откройте **Проводки** — баланс должен быть нулевым. Чтобы отдельно проверить приёмку, выберите ПВЗ Мира, примите одну единицу S, а в ручной форме заказа укажите эту партию.
2. **Хаб C / полка A.** В той же форме выберите **Дальний, через хаб** или **С полки**. Для дальнего заказа расстояние не проходит фильтр.
3. **Возврат.** У выданного заказа нажмите **Возврат → В путь → Принять возврат**. Бонус за выдачу сторнируется, продавец платит обратную логистику 50 ₽; если сборка была оплачена — сторнируется и она. Товар по возможности остаётся в ПВЗ выдачи (партия того же SKU), иначе уходит в партию отправителя. Отдельная транспортировка возврата на хаб не моделируется.
4. **Срыв рейса.** На свежих данных нажмите **Сбой** у рейса. Если нет другого рейса, проходящего фильтры, заказ переключится на C. Пересорт при приёмке пересчитывается: фактический класс S↔M принимается по новому тарифу, фактический L — отказ, товар идёт через хаб.
5. **Долгое хранение.** Примите партию, не выдавайте её, сдвиньте модельное время через `POST /api/time/advance` (или кнопкой **+1 день**). Через 7 дней без продаж появится алерт, через 15 — уведомление о вывозе (10 ₽/УМ-день + 35 ₽ за единицу) и блокировка пополнения SKU. Сам вывоз и ежедневное начисление на непроданный остаток ещё не реализованы; контроль тарифа за 14 дней (54 ₽ с продавца, 42 ₽ ПВЗ за S) есть в тестах ядра.

Раздел **Модель** независимо сравнивает схемы на одном потоке заказов (`seed=42`), строит график окупаемости, чувствительность к трём параметрам и экономику пилота (пороги 116/62 заказа на рейс после постоянных расходов 60 000 ₽/мес). Это упрощённая модель: она не имитирует календарь рейсов, срывы, возвраты и непроданные остатки потока и не доказывает достижение целевых −5% для пилота. В разделе **Продавец** — полная юнит-экономика по бизнес-модели v0.3: комиссия 15%, эквайринг 1,5%, логистика 65/95 ₽, обратная логистика 50 ₽, налог УСН 6%.

## Стек и структура

| Путь | Назначение |
| --- | --- |
| `core/` | Python, `Decimal`: экономика, фильтры A/B/C, проводки, симулятор |
| `api/` | FastAPI, Pydantic, SQLAlchemy, PostgreSQL в Docker / SQLite локально |
| `ui/` | React, TypeScript, Vite, Ant Design, TanStack Query, Recharts |
| `data/` | Воспроизводимые данные интерфейса, независимые от симулятора |
| `tests/` | pytest: формулы, маршруты, конкурентный резерв, API на SQLite |
